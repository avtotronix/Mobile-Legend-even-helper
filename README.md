# 🍔 MLBB Undersea Restaurant Auto-Bot (Android)

Автоматический бот-помощник для кулинарного события **Undersea Restaurant** (коллаборация SpongeBob / Undersea Bash / Friend Fest) в **Mobile Legends: Bang Bang**.

## 🚀 Особенности

* **Однокнопочный интерфейс:** Открыл приложение -> Нажал `ЗАПУСТИТЬ БОТА` -> Перешел в игру.
* **Плавающий виджет поверх игры:** Кнопки `[ ▶ СТАРТ ]` и `[ ⏸ ПАУЗА ]` поверх экрана игры.
* **Полная автоматизация 6 блюд:**
  * 🍔 **Бургеры:** Жарка котлет на 4 конфорках + Сборка (булка, котлета, томат, салат).
  * 🍕 **Пицца:** Сборка теста, лука, ветчины + Запекание в печи.
  * 🍟 **Фритюр:** Картофель фри и жареная курица.
  * 🥤 **Напитки:** Кола и мягкое мороженое.
  * 👥 **Отдача:** Мгновенное обслуживание всех 3 очередей клиентов и приоритет для срочных заказов (Rush Orders).
* **Работает без ROOT** (через стандартный `AccessibilityService` и `SYSTEM_ALERT_WINDOW`).
* **Адаптивные координаты:** Автоматически подстраивается под любое разрешение экрана (1080p, 1440p, 720p).

---

## 📂 Структура проекта

* `app/` — Исходный код нативного Android-приложения (Kotlin, Android SDK 34).
  * `MainActivity.kt` — Простой минималистичный экран с 1 кнопкой.
  * `FloatingOverlayService.kt` — Плавающий поверх MLBB виджет управления.
  * `BotAccessibilityService.kt` — Служба автоматического выполнения нажатий.
  * `CookingEngine.kt` — Игровой конвейер и расчет таймингов готовки.
* `scripts/mlbb_undersea_restaurant_bot.js` — Готовый автономный скрипт для запуска через **AutoX.js** без компиляции.

## 🛠 Способы запуска

### Вариант 1: Через AutoX.js (Самый быстрый, 1 минута)
1. Установите APK **AutoX.js** на свой Android-телефон.
2. Включите в настройках телефона «Специальные возможности» для AutoX.js.
3. Откройте файл `scripts/mlbb_undersea_restaurant_bot.js` в приложении.
4. Запустите скрипт — поверх экрана появится плавающее меню с кнопкой `▶ СТАРТ`.
5. Откройте Mobile Legends, зайдите в ресторан и нажмите `▶ СТАРТ`.

### Вариант 2: Сборка нативного APK через Android Studio / Gradle
```bash
./gradlew assembleDebug
```
Собранный файл будет доступен в `app/build/outputs/apk/debug/app-debug.apk`.
